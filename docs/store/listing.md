# Chrome 웹 스토어 등록 문구

개발자 대시보드에 그대로 붙여넣는다. 업로드할 파일: `./pack.sh`로 만든 `dist/fitmyphoto-<버전>.zip`.

## 스토어 등록정보
- **이름**: FitMyPhoto
- **요약** (manifest `description`, 132자 이하): 업로드 칸 안내문을 읽고, 고른 이미지를 그 규격에 맞게 바꿔 넣어준다. 이미지는 브라우저 밖으로 나가지 않는다.
- **카테고리**: 생산성 (Productivity)
- **언어**: 한국어
- **아이콘**: `icons/icon128.png`
- **스크린샷**: `docs/store/screenshot-1280x800.png`
- **작은 프로모션 타일**: `docs/store/promo-440x280.png`

### 상세 설명
업로드 칸 옆에 적힌 안내문(크기·용량·형식)을 읽고, 고른 사진을 그 규격에 맞게 바꿔서 넣어줍니다.

"300×400 픽셀 이상, 200KB 이하, JPG만" 같은 규격 때문에 사진 편집 사이트를 따로 찾을 필요가 없습니다. 규격을 직접 입력할 필요도 없습니다. 페이지에 적힌 문구를 읽어서 알아서 맞춥니다.

• 이런 곳에서 씁니다: Google Play Console 스크린샷·아이콘, Q-Net·국가고시·여권 등 증명사진 등록처럼 규격이 틀리면 거부만 하는 곳
• 쓰는 법: 평소처럼 사진을 고르면, 맞출 게 있을 때만 카드가 뜹니다. 잘라내기 또는 여백 넣기를 고르고 "맞춰서 넣기"를 누르세요.
• 이미 맞거나 규격 문구가 없으면 아무것도 하지 않고, 무엇이 잘못되든 원본은 반드시 들어갑니다.
• 사진과 페이지 내용은 브라우저 밖으로 나가지 않습니다. 네트워크 요청·저장소·분석 도구를 쓰지 않습니다.

## 개인정보 보호 탭
- **단일 목적**: 파일 업로드 칸에서 사용자가 고른 이미지를, 그 칸 근처에 적힌 업로드 규격(크기·용량·형식)에 맞게 변환해 넣는다.
- **권한 사용 근거 — 호스트 권한 (콘텐츠 스크립트 `<all_urls>`)**: 업로드 칸은 어느 사이트에나 있고 규격 문구도 그 페이지에만 적혀 있으므로, 모든 사이트에서 파일 선택 이벤트를 받고 업로드 칸 근처 글자를 읽어야 한다. 읽은 글자와 이미지는 브라우저 안에서만 쓰고 저장·전송하지 않는다. 그 밖의 권한은 요청하지 않는다.
- **원격 코드 사용**: 아니요
- **데이터 사용**: 수집하는 항목 없음 (모든 항목 체크 해제)
- **개인정보처리방침 URL**: https://github.com/YoonGangHoon/FitMyPhoto/blob/main/PRIVACY.md
